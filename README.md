# 꽁밥 운영

꽁밥(https://yu-jusang.github.io/kkongbap/)을 운영하는 사람만 쓰는 화면이다. 공개 사이트에는 링크하지 않고 검색 엔진에도 노출하지 않는다(`noindex`).

**주소:** https://yu-jusang.github.io/kkongbap-admin/

## 꽁밥과 연동

- 같은 주소(`yu-jusang.github.io`) 아래에 있어 꽁밥의 `core.js`(공지 해석, 상태 판단, 주간·시즌 묶음)와 `content.js`(출처, 시즌 묶음, 제보 폼)를 그대로 불러 쓴다. 해석 규칙을 고치면 두 사이트에 함께 적용된다.
- 행사 자료는 GitHub API로 `Yu-Jusang/kkongbap`의 `data/events.json`을 읽고, ‘변경 저장’을 누르면 그 파일에 커밋한다. 커밋하면 꽁밥이 1~2분 뒤 다시 배포된다.
- 학식은 꽁밥 저장소의 `menu.yml` 실행 기록을 보여 주고, ‘지금 가져오기’로 수동 실행한다.

## 토큰

저장과 학식 수동 실행에는 fine-grained personal access token이 필요하다. Repository access는 `Yu-Jusang/kkongbap` 하나, 권한은 Contents: Read and write와 Actions: Read and write만 준다. 토큰은 이 브라우저의 sessionStorage(‘기억하기’를 켜면 localStorage)에만 두고 GitHub API 외에는 보내지 않는다. 같은 주소 아래 다른 페이지도 같은 저장소를 쓰므로, 공용 기기에서는 기억하기를 끄고 쓴 뒤 ‘토큰 지우기’를 누른다.
